# 🎮 Carpeta de ROMs

Esta carpeta contiene los archivos ROM para el emulador local.

## ⚠️ IMPORTANTE - LEGALIDAD

**Solo agrega ROMs que poseas legalmente:**
- ROMs de juegos que tengas físicamente
- ROMs homebrew (creados por la comunidad)
- ROMs de dominio público
- Demos oficiales

**NO agregues ROMs pirateados o copyrighted sin permiso.**

## 📁 Estructura

```
roms/
├── snes/          # Super Nintendo ROMs (.smc, .sfc)
├── gba/           # Game Boy Advance ROMs (.gba)
├── n64/           # Nintendo 64 ROMs (.n64, .z64)
├── genesis/       # Sega Genesis ROMs (.bin, .md)
└── arcade/        # MAME ROMs (.zip)
```

## 🎯 ROMs Homebrew Recomendados

### SNES

- **Rick Dangerous**: Conversion homebrew

### GBA  
- **Goodboy Galaxy**: Juego indie para GBA

### N64
- **Homebrew demos**: https://n64squid.com/

## 🔧 Uso

1. Coloca tus ROMs en la carpeta correspondiente
2. Ve a `/emulator` en el sitio web
3. Selecciona sistema y juego
4. ¡Disfruta sin problemas de CORS!

## 📝 Notas

- Los archivos deben tener las extensiones correctas
- Para PSX necesitas archivos BIOS adicionales
- MAME requiere ROMs específicas con nombres exactos
